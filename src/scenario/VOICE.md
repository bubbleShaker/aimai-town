# 文体の作法

このディレクトリのテキストを書き足すときの決まり。
町の言葉が継ぎ接ぎにならないように、実例つきで残しておく。

## 語り手

主人公は名も性別も持たない **「あなた」**。
語り手は「あなた」の肩越しにいて、心の中までは踏み込まない。

- 「あなたは訊く。それは、譲ったということですか。」… 行動として書く
- ~~「あなたは戸惑いを覚えた」~~ … 感情を名指ししない

**感情は書かず、動作と情景に預ける。** 灯の揺れ、返せない言葉、止まらない手。

```ts
{ text: '答えないでいると、灯がわずかに揺れた。' }
{ text: '返す言葉が、うまく見つからない。' }
```

## 一行の長さ

スマホ縦持ちで **2 行に収まる長さ**（およそ 30 字以内）を上限にする。
長い思考は複数行に割り、一行ずつ送らせる。送る間が読者の考える時間になる。

```ts
{ text: 'あなたはそれを、幼いと呼びたくなる。' },
{ text: 'そう呼びたくなること自体が、少し引っかかる。' },
```

一行目で断じ、二行目で自分に返す。この折り返しがこの作品の基本のリズム。

## 地の文とセリフ

`speaker` を付けるとセリフ、付けなければ地の文。
**セリフは短く、地の文で受ける。** セリフを続けるのは、相手が畳みかけるときだけ。

```ts
{ speaker: '親方', text: '手は自分のものだ。誰にも預けない' },
{ speaker: '親方', text: 'だがな、隣の織り目とは合わせる' },
{ speaker: '親方', text: '合わせないと、布にならんからだ' },
{ text: 'あなたは訊く。それは、譲ったということですか。' },
```

セリフに句点（。）は打たない。地の文には打つ。声と記述を、記号でも分ける。

## 断片の書き方

断片は**その人が本気で言っている一文**。中立的な要約にしない。

- 10〜25 字。表示時に「」で囲まれるので、鉤括弧は入れない
- 言い切る。「〜かもしれない」で濁さない（濁るのはプレイヤーの仕事）
- 出典（`source`）は人ではなく**その言葉が生まれた場所**を含めて書く

```ts
{ id: 'f-approval', text: '認められたい、はいちばん古い火だ', source: '広場の子ども' }
{ id: 'f-cloth', text: '織るのは一人でもできる。着るのは一人ではない', source: '機屋の奥の布' }
```

**断片どうしは両立しなくてよい。** 矛盾する二枚が揃っていることが、扉の前提になる。

## 登場人物の声

| | 話し方 |
| --- | --- |
| 子ども | 短く、繰り返す。取り繕わない。「ねえ、すごいって言ってよ」 |
| 名もなき人 | 言い差す。相手に投げて終わる。「あんたも、そうだろう」 |
| 織り手の親方 | 断定と留保を並べる。手を止めない。「ちがう。合わせただけだ」 |
| 戸（扉） | 問い返す。答えを待たない。古風で、少し高圧的。「では、合わせることは何だ」 |

新しい住人を作るときは、**その人が担う思想の一面**を先に決めてから声を決める。
声が先だと、ただの賑やかしになる。

## 扉の書き方

扉は `tension` の二枚を突きつけ、差し出された一枚に `responses` で応える。

- **返答は、差し出した断片を肯定も否定もしない。** 問い返すか、別の面を見せて終わる
- 最後の一行は、開くことを描写して締める（開く理由は説明しない）
- どの断片にも返答を用意する。到達時に持ちうる断片への返答が欠けるとテストが落ちる

```ts
'f-solitude': {
  lines: [
    { speaker: '戸', text: 'では、なぜ機の前に立っている' },
    { text: 'あなたは言う。布を織るためだ。' },
    { speaker: '戸', text: '布は、誰かが着るために織るのだろう' },
    { text: '戸は静かに開いた。答えを待ってはいなかった。' },
  ],
  shift: { distance: -2, certainty: 1 },
},
```

`shift` は −2〜+2 の範囲。
`distance` は負が孤独・正が関わり、`certainty` は負が曖昧・正が確信。
**プレイヤーには数値を見せない。** 迷った選択は 0 に寄せてよい。

## 禁じ手

- 説明しない。思想の解説をキャラクターに語らせない
- 答えを言わない。とくに終盤ほど言わない
- 教訓にしない。「大切なのは〜」を書かない
- 専門用語を使わない（承認欲求、自己肯定感、社会性 …）。
  かわりに、灯・火・布・霧・水など町のものに置き換える
